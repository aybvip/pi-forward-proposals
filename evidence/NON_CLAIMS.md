# Non-claims

This file lists what the repository does **not** claim. If a sentence here conflicts
with a proposal, the non-claim wins.

---

## About adoption

- No proposal is accepted, approved, reviewed, or endorsed by Pi Network, the Pi
  Core Team, or any PiRC maintainer.
- A GitHub issue, a pull request, or a link from this repository is not acceptance.
- "Draft v0.1" is not a status granted by Pi. It is this repository's own label.
- The IDs `CP-01` … `CP-04` are local. They are not PiRC numbers and do not reserve a
  PiRC number.

## About identity and data

- This repository holds no personal data, no KYC data, no wallet keys, and no seed
  phrases.
- No proposal creates a global Pioneer identity or a cross-app profile.
- No proposal claims that a self-declared GitHub handle proves a Pi identity.
- No proposal claims that a `uid` is stable across apps or across sessions.

## About "mined Pi"

- No proposal claims that an individual coin's mining origin can be observed.
- CP-01 does not tag coins. It uses account-level eligibility, and it says so.
- A claim that a specific transfer is "mined Pi" is not evidence under this
  repository's rules.

## About money

- Nothing here is financial, investment, legal, tax, or accounting advice.
- No proposal promises a price, a return, a yield, or liquidity.
- CP-04's reward is issuer-funded and conditional. Coverage can fail.
- CP-02's rewards are not a claim that a token will have value.
- CP-03's levels are not a price signal.

## About verification

- No proposal is an audit of Pi, PiRC1, PiRC2, the Launchpad, any issuer, any
  reserve, or any contract.
- CP-03's `L2` means "a registry reviewer saw evidence of a legal entity"; it does
  not mean "the business is lawful, solvent, or good".
- CP-03's `L3` means "an attestor signed a reserve snapshot"; it does not mean "the
  reserve will always be sufficient".
- CP-04's coverage ratio is only as good as the attestation behind it.
- The tests in this repository check arithmetic and shape. They do not check truth.

## About scope

- No proposal changes Pi's consensus, issuance, mining, or token supply.
- No proposal modifies the PiRC2 contract.
- No proposal guarantees that a registry will exist or that a maintainer will accept
  a record.
- No proposal solves Sybil resistance, legal classification, or cross-border
  enforcement.

## About the repository itself

- The CI badge means the tests passed on a commit. It does not mean the ideas are
  correct.
- The presence of a source link does not mean the source says what a proposal wishes
  it said. The quoted location is part of the claim.
- A proposal can be withdrawn. Withdrawal is a valid outcome.
